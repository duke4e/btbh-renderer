Portati

  • Mesh, model, material i runtime Assimp parity adapter
  • Instancing, persistent city chunk bufferi i frustum culling
  • Skeletal animacija, animation player i tree
  • Directional/spot svjetla i soft shadows
  • Procedural sky, cubemap IBL i manualni tonemap
  • SSAO, SMAA, LUT, CAS i tilt-shift
  • Samo korišteni primitive mesh generatori

Zamijeniti dubljim interfaceom

  • Raylib math/color/image tipovi → projektni POD tipovi
  • Raw environment pointer → validirani frame/environment opis
  • Runtime GLSL loader → offline shader varijante + reflection
  • Ručno buffer reuse pravilo → frame-local arena + fences
  • Raylib immediate 2D/text → batched Canvas2D
  • OpenGL state cache → eksplicitni immutable pipelineovi

Ne portati

  • OpenGL, rlgl i raylib compatibility surface
  • Decali i reflection probe capture
  • Kinematics/collision i r3d pack sustav
  • Custom sky-shader sustav
  • SSIL, stari SSGI, SSR, DoF i volumetric fog
  • Auto exposure, bloom i ostali trenutno ugašeni passovi
  • Nekorišteni primitive generatori i debug helperi
