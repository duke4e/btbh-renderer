Ownership i frame lifecycle

Svaki resurs ima jednog vlasnika; frame je jednosmjeran i nema ponovne uporabe upload buffera prije GPU fencea.

Platform module

Vlasnik SDL lifecyclea, windowa, eventa, inputa i vremena. SDL tipovi ostaju unutra.

Asset module

CPU dekodiranje i import. U parity fazi Assimp adapter; kasnije offline asset pack.

Renderer module

GPU device, swapchain, pipelineovi, resursi i frame graph. Izlaže samo generacijske opaque handleove.

Game + alati

Posjeduju scene opise i handleove, ali nikad SDL_GPU objekte, command buffere ili sync.
