Migracija i release gateovi

Legacy put ostaje uporabljiv dok novi renderer ne dokaže parity. Svaka faza ima dokaz; nijedna ne prolazi samo zato što se builda.

Faza 0BaselineGolden slike, perf scene, API usage manifest i capture svih launch modeova.
Faza 1Game seamoviProjektni math, platform, Canvas2D i renderer interface; legacy raylib adapter održava igru.
Faza 2GPU spikeSDL3 + SDL_GPU, novi G-buffer, PBR, sjene, animacija, transparentnost i compute na oba backenda.
Faza 3Feature parityInstancing, IBL, SSAO, surface varijante, post chain, asset i 2D/text put.
Faza 4Svi modeoviGame, combat lab, city editori i particle editor rade kroz novi renderer.
Faza 5RC + kameraProduction RC, quality tierovi i deterministički CameraProfile level-up cut.
Faza 6Delete legacyUkloniti r3d OpenGL, raylib, rlgl, stare shadere, binarne libraryje i neportane featuree.

Spike gate

Metal na M1 i Vulkan na GTX 1060/RX 580 moraju proći obvezne featuree, shader reflection i GPU capture bez portability workarounds koji cure kroz interface.

Parity gate

Automatski perceptual diff cilja SSIM ≥ 0,98 za odobrene scene; gameplay cue maske ne smiju nestati. Prvi novi golden update traži ljudski review.

Performance gate

1080p p95 frame ≤ 16,67 ms na minimum hardveru; RC p95 ≤ 4,0 ms. Capture mora pokazati uzrok svake regresije iznad 5%.

Mode gate

Svaki launch mode ima smoke capture, resize/high-DPI provjeru, asset load/unload i clean shutdown na macOS-u i Windowsu.

Removal gate

Nula runtime linkova i source includeova za raylib/rlgl/OpenGL; samo povijesna dokumentacija smije spominjati legacy nazive.

Rollback gate

Legacy ostaje odvojiv build/runtime izbor do završetka faze 5. Nakon removal commita rollback je git revert, ne trajni compatibility shim.

Test matrica
UnitHandle generation, allocator/ring arena, frame-graph lifetime/cycles, math/projection i CameraProfile determinism.
Build-timeShader compile, reflection manifest, binding/format validation i zabranjeni dependency scan.
GPU integrationMesh/PBR, shadow atlas, skinning, instancing, transparent, storage compute i resize/device teardown.
Visual/perfGolden slike i benchmark scene na stvarnim Metal/Vulkan referentnim strojevima.
Failure ponašanje
Nedostaje obvezni GPU featureInit prekida s jasnim backend/device/feature izvještajem. Nema tihog D3D12 fallbacka.
RC nije dostupanLogirani razlog; nastavi s IBL + ambient + SSAO.
Shader/reflection mismatchBuild mora pasti; production ne pokušava runtime pogoditi binding.
Device lossPrva verzija završava kontrolirano s dijagnostikom; live recovery nije skriveni v1 scope.
